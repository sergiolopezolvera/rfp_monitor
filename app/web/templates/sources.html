How it works

Each source is processed in three steps. Run them in order:

  1. Find new — checks the site’s listing and saves opportunities we haven’t seen.
  2. Read details — opens each new posting and saves its full description.
  3. Analyze fit — asks the AI whether each posting matches the firm’s services.
