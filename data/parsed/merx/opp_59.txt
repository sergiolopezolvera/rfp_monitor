Description:
The Work generally includes but is not necessarily limited to the following:
• Addition to the front of the building including: foundations, walls, roof, new entry door.
• Upgrade of the interior of the building including:
• Remove walls, flooring and ceilings, including asbestos containing materials.
• Construct new partitions.
• Install new floors and ceilings.
• Infill some existing window openings.
• Replace all windows.
• Increase the insulation in the attic.
• Install new washrooms.
• Replace the existing kitchen with a new kitchen.
• Construct a covered enclosure between the main building and detached garage.
• Upgrade the interior of a portion of the garage.
• Change the electrical service entrance.
• Rewire the building to suit the new layout.
• Install new lights.
• Install new data outlets through.
• Modify the existing HVAC system to suit the new layout.
• Replace the water and sanitary service to the building.
• Replace the plumbing piping and fixtures in the building.
• Work is to include all associated: removals, wiring, controls, piping, ductwork, patching, commissioning, balancing, excavation and landscaping.
• All other Work as detailed on the Project Drawings and/or specified herein.
